# Pemeriksaan desain IPH Kota Batu

Perubahan ini mengikuti referensi pemilik dan keenam skill antislop di `.opencode/skills`. Arah dan alasan keputusan visual dicatat dalam [DESIGN.md](../DESIGN.md): ENERGY 2 / RHYTHM 2 / MOTION 1. Cakupan pemeriksaan adalah frontend yang diperbarui, dengan regresi API pada database pengujian terpisah.

## Bukti verifikasi

- PASS: 146 tes backend, 13 file. Login, hak akses, data, rapat, antrean WhatsApp dan deployment frontend tetap lulus.
- PASS: 132 pemeriksaan browser Edge pada 320, 390, 768, 1024, dan 1440 px, kedua tema; tidak ada error runtime.
- PASS: 23 pemindaian WCAG A/AA otomatis, termasuk menu utama, profil, pengaturan akun, dialog pegawai dan login, tidak menemukan pelanggaran pada keadaan yang diuji. Ini bukan klaim sertifikasi atau pengganti pengujian semua teknologi bantu.
- PASS: build frontend/backend dan ESLint. Vite masih memberi peringatan ukuran chunk, tanpa kegagalan build.
- PASS: audit dependency frontend, 0 vulnerability setelah pembaruan yang kompatibel.
- PASS: `git diff --check`; `.env`, artefak browser dan paket lokal diabaikan Git.

## Catatan interaksi browser

| Kontrol | Hasil |
|---|---|
| Masuk, formulir kosong | Menampilkan validasi email/kata sandi. |
| Tampilkan kata sandi | Mengganti jenis input; label berubah sesuai keadaan. |
| Login | Respons API tiruan membuka dashboard dengan hak akses yang sesuai. |
| Dashboard publik | Terbuka dari beranda tanpa meminta akun. |
| Delapan menu | Semua halaman tampil, tidak ada error runtime atau overflow dokumen pada lima lebar, kedua tema. |
| Tema | Light/dark berubah; tidak mengubah data atau hak akses. |
| Menu akun | Membuka profil/pengaturan; label dan formulir diperiksa. |
| Dialog pegawai | Fokus tetap di dialog; Escape menutup dan mengembalikan fokus. |
| Pilihan minggu siaran | Link dashboard berubah ke minggu yang dipilih. |
| Edit dan simpan draf | Pesan yang dikirim ke mock API memakai teks yang disunting. |
| Kirim siaran | Mock menerima `rekapId` dan teks; UI menampilkan status antrean. Tidak mengirim WhatsApp nyata. |
| Salin teks dan link | Clipboard memuat `https://iph.bpskotabatu.com/#/publik` dengan tahun/bulan/minggu yang sesuai. |
| Tamu dan petugas | Navigasi administrator disembunyikan. Backend tetap memvalidasi hak akses melalui tes regresi. |
| Zoom 200% | Halaman siaran tetap dapat digunakan tanpa overflow dokumen. |
| Error beranda | Pesan gagal tampil dan tombol coba-lagi memuat ulang. |

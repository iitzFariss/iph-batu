## Batas pemeriksaan reminder

Riwayat database menunjukkan pengingat manual berhasil, satu undangan kedaluwarsa, dan satu teks siaran gagal HTTP 401 setelah tiga percobaan. Tidak ada pengiriman lama yang diulang dalam pekerjaan ini. Token pada `.env` laptop sekarang lolos dry run. HTTP 401 historis tidak membuktikan apakah proses laptop atau server yang memakainya, karena keduanya memakai antrean yang sama. Log kegagalan baru menyertakan identitas host dan PID tanpa nomor penerima atau token, agar proses pemroses bisa ditemukan.

Perbaikan penjadwalan berlaku untuk rapat baru atau revisi rapat berikutnya. Rapat yang disimpan setelah jam pengingat tetap mendapat antrean pengingat selama waktu mulai belum lewat. Ini tidak membuat ulang pesan rapat lama. Status unknown tetap tidak diulang otomatis untuk menghindari pesan ganda.

Jika ada HTTP 401 baru, jalankan `npm run wa:check` dari folder `server` pada masing-masing mesin, samakan token dengan workflow IPH dan restart backend mesin yang diubah. Konfigurasi produksi belum diperiksa melalui SSH pada pekerjaan ini. Schema `presensi`, migration, data rapat dan `.env` tidak diubah.

# Pembaruan perbaikan admin dan petugas

Temuan, perubahan, dan bukti pengujian ada di `docs/final-review-2026-10-19.md`. Paket ini memuat perbaikan 19 Oktober serta perubahan komoditas/pengingat notulensi 16 Oktober yang masih ada di workspace. Tidak diperlukan migration atau penggantian `.env` server.

Di PowerShell laptop, dari folder project:

```powershell
scp deploy/package.local/iph-batu-update-2026-10-19.tar.gz bps@192.168.100.10:~/
ssh bps@192.168.100.10
```

Di SSH, jalankan blok berikut. Build baru disiapkan sebelum mengganti hasil build yang sedang digunakan. Folder build lama dan sumber lama disimpan sebagai cadangan.

```bash
cd /opt/iph-batu &&
tar -czf "$HOME/iph-batu-source-before-$(date +%Y%m%d-%H%M%S).tar.gz" server/src src &&
tar -xzf ~/iph-batu-update-2026-10-19.tar.gz &&
npm run build -- --outDir dist-next &&
npm --prefix server run build -- --outDir dist-next &&
cp -a dist/assets/. dist-next/assets/ &&
mv dist "dist-before-$(date +%Y%m%d-%H%M%S)" &&
mv dist-next dist &&
mv server/dist "server/dist-before-$(date +%Y%m%d-%H%M%S)" &&
mv server/dist-next server/dist &&
sudo systemctl restart iph-batu &&
sudo systemctl is-active iph-batu &&
curl -fsS https://iph.bpskotabatu.com/api/health
```

Jika ada langkah gagal, perbaiki penyebabnya sebelum melanjutkan. Jangan menjalankan reset/seed database. Untuk rollback, pilih folder `dist-before-*` frontend dan backend yang baru dibuat, simpan build saat ini dengan nama cadangan lain, lalu kembalikan kedua folder lama ke `dist` dan `server/dist` sebelum restart layanan.

Setelah berhasil, lakukan Ctrl+Shift+R pada browser. Periksa hasil perbaikan memakai akun uji dan data uji:

1. NIP pendek atau duplikat menampilkan error di dalam dialog dan isian tidak hilang.
2. Ganti password berhasil dengan konfirmasi yang cocok. Password salah dan konfirmasi tidak cocok memberi penjelasan yang sesuai.
3. Perubahan profil terlihat di header. Batal edit menampilkan data tersimpan.
4. Sesi lain yang diakhiri kehilangan akses API; sesi saat ini tetap dapat digunakan.
5. Rekap bisa menyimpan angka negatif/desimal koma; nilai kosong atau periode duplikat ditolak dengan pesan dalam dialog.
6. Petugas hanya melihat fitur sesuai perannya dan dapat mengisi notulensi rapat yang menugaskannya sebagai notulis.

Pemeriksaan token WhatsApp tanpa mengirim pesan:

```bash
cd /opt/iph-batu/server
sudo -u iph-batu npm run wa:check
```

Konfigurasi token n8n yang tidak cocok tetap harus disamakan pada server dan workflow. Pembaruan ini tidak mengganti konfigurasi tersebut.

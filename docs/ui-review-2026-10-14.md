# Pemeriksaan UI, 14 Oktober 2026

Versi ini mengganti komposisi beranda, dashboard, login, ruang kerja, formulir IPH, rapat, pegawai, monitoring, dan siaran. Arah visual dan alasan keputusan tercatat di [DESIGN.md](../DESIGN.md): ENERGY 2 / RHYTHM 2 / MOTION 1. Keenam skill antislop proyek diterapkan saat pengerjaan.

## Bukti pengujian

- PASS: build produksi frontend dan ESLint.
- PASS: 146 tes backend dalam 13 file, memakai database pengujian terpisah.
- PASS: 162 pemeriksaan browser Edge, termasuk delapan halaman pada 320, 390, 768, 1024, dan 1440 px, kedua tema, dan zoom 200%. Tidak ada error runtime tak terduga pada halaman yang diuji.
- PASS: 23 pemindaian WCAG A/AA desktop, termasuk profil, pengaturan, dialog pegawai dan login; 20 pemindaian tambahan pada 320 px, kedua tema. Tidak ada pelanggaran otomatis pada 43 keadaan yang dipindai.
- PASS: kegagalan pemuatan modul halaman disimulasikan. Pesan pemulihan tampil, tombol muat ulang memulihkan halaman, dan navigasi kembali berfungsi.
- PASS: kontras dihitung dengan checker skill. Teks sekunder pada kertas 5,10:1; teks sekunder gelap 7,89:1; tombol primer 6,96:1; teks navigasi 8,80:1; anotasi peringatan grafik 6,90:1 terang dan 8,07:1 gelap. Batang andil netral 3,70:1 terhadap jalurnya, memenuhi batas nonteks 3:1.
- PASS: file JavaScript utama produksi sekitar 255 kB sebelum gzip, dibanding sekitar 854 kB pada build sebelumnya. Modul grafik terpisah sekitar 356 kB dan dimuat ketika diperlukan. Ini perbandingan ukuran file utama, bukan klaim pengurangan total unduhan atau hasil pengukuran kecepatan jaringan.
- PASS: `git diff --check`; `.env`, data pengujian browser, dan paket lokal tetap diabaikan Git.

Artefak lokal: `.ui.local/evidence.json`, `.ui.local/accessibility.json`, `.ui.local/mobile-accessibility.json`, serta gambar `v2-*` dan `mobile-*`. Data pada gambar dan interaksi browser adalah simulasi berlabel uji. Tidak ada penulisan ke database kantor atau pengiriman WhatsApp nyata selama pemeriksaan UI ini.

## Liveliness dan craftsmanship

- PASS, dial: ENERGY 2 / RHYTHM 2 / MOTION 1 tercatat dan sesuai komposisi laporan, formulir, serta navigasi.
- PASS, focal point: IPH dan tren pada dashboard, tugas halaman pada pengelolaan, dan draf serta penerima pada siaran.
- PASS, whitespace: jarak memisahkan konteks halaman, kelompok formulir dan baris data; tidak ada bagian untuk mengisi template.
- PASS, accent: aksi primer hijau dibedakan dari tautan sekunder dan kondisi data.
- PASS, identity motif: periode pelaporan, angka tabular dan susunan bidang laporan berulang pada beranda, dashboard dan siaran.
- PASS, Design Read: dicatat sebelum implementasi, dengan alasan keputusan dalam DESIGN.md.
- PASS, C-1: keputusan visual mempunyai alasan yang tertulis.
- PASS, C-2: interaksi utama terhubung ke API dan diuji; kontrol dekoratif yang tidak mempunyai fungsi tidak ditambahkan.
- PASS, C-3: isi mengikuti pekerjaan TPID, tanpa pricing, testimoni, atau bagian pemasaran.
- PASS, C-4 pada cakupan uji: tema, viewport, zoom, keyboard, kondisi data dan kegagalan modul diperiksa.
- PASS, C-5: angka berasal dari API, data browser secara eksplisit simulasi, dan klaim performa dibatasi pada ukuran build yang diukur.

Pemeriksaan otomatis ini tidak menggantikan uji dengan semua pembaca layar, perangkat fisik, atau keyboard virtual. Pengiriman WhatsApp nyata tidak diulang pada pembaruan UI ini. Hak akses, API, schema database dan workflow n8n tidak diubah.

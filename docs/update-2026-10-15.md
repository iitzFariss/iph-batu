# Update UI dan reminder, 15 Oktober 2026

Paket `deploy/package.local/iph-batu-update-2026-10-15.tar.gz` mencakup source frontend serta perubahan backend reminder dan pemeriksaan n8n. Tidak menyertakan `.env`, kredensial produksi, node_modules, database atau migration. Paket frontend 14 Oktober tidak memuat perbaikan reminder ini.

Paket telah diperbarui dengan penomoran draf berurutan, panel rekap tunggal dan perapian tombol. Pemeriksaannya ada di [laporan layout](layout-review-2026-10-15.md).

Revisi terbaru menyusun panel fitur secara vertikal agar tidak ada kolom kosong di bawah panel yang lebih pendek. Lihat [laporan susunan panel](stack-review-2026-10-15.md).

Untuk domain yang sudah diperbarui tetapi mengalami HTTP 401 atau undangan/pengingat bersamaan, tersedia [perbaikan WhatsApp khusus backend](whatsapp-fix-2026-10-15.md). Paket utama juga mencakup koreksi tersebut.

## Pemeriksaan lokal

Dari folder utama project:

```powershell
npm run dev
```

Buka http://localhost:5173 dan biarkan koneksi DBeaver `db_magang` aktif. Dari terminal kedua, periksa konfigurasi n8n tanpa mengirim pesan nyata:

```powershell
npm --prefix server run wa:check
```

Restart `npm run dev` setelah mengubah `.env`. Backend dan frontend dijalankan bersama oleh perintah tersebut.

## Mengirim paket dari laptop

```powershell
scp .\deploy\package.local\iph-batu-update-2026-10-15.tar.gz bps@192.168.100.10:~/
```

## Memasang melalui SSH

Pembaruan ini belum dijalankan ke server. Jalankan dari akun `bps` di server, satu per satu. Pertahankan `.env` produksi yang sudah berfungsi. Tidak perlu mengulang migration atau transfer data.

```bash
cd /opt/iph-batu
pwd
curl -fsS http://127.0.0.1:5011/api/health
tar -czf ~/iph-batu-runtime-before-2026-10-15.tar.gz dist server/dist
tar -xzf ~/iph-batu-update-2026-10-15.tar.gz -C /opt/iph-batu
npm ci --include=dev
npm run build -- --outDir dist-next
npm --prefix server run build -- --outDir dist-next
```

Jika salah satu build gagal, berhenti dan biarkan folder `dist` lama melayani aplikasi. Jika keduanya berhasil:

```bash
cp -an dist/assets/. dist-next/assets/
mv dist "dist-before-$(date +%Y%m%d-%H%M%S)"
mv dist-next dist
mv server/dist "server/dist-before-$(date +%Y%m%d-%H%M%S)"
mv server/dist-next server/dist
sudo systemctl restart iph-batu
sudo systemctl status iph-batu --no-pager
curl -fsS https://iph.bpskotabatu.com/api/health
```

Pertukaran folder memiliki jeda singkat. Buka web dan gunakan Ctrl+Shift+R untuk memuat versi baru. Periksa dashboard, kelola rapat, monitoring, filter status dan siaran. Pengingat untuk rapat yang sudah lewat tidak dikirim ulang oleh pembaruan ini.

## Jika muncul HTTP 401 n8n

Laptop dan server memakai antrean yang sama. Token di setiap proses backend harus cocok dengan workflow IPH n8n. Jalankan pemeriksaan dari folder `server` dengan akun service yang memiliki izin membaca `.env` produksi:

```bash
cd /opt/iph-batu/server
sudo -u iph-batu npm run wa:check
```

Jika token ditolak, edit `.env` produksi sesuai prosedur kantor dan samakan `N8N_WHATSAPP_TOKEN` dengan token workflow IPH. Jangan mengirim token melalui chat atau Git. Setelah perubahan, restart `iph-batu`. Ulangi pemeriksaan di laptop bila backend lokal juga berjalan. Pesan gagal yang masih memenuhi syarat dapat diulang melalui Monitoring rapat; status unknown perlu diperiksa di n8n sebelum tindakan lanjutan.

Log `whatsapp.pengirimanGagal` menyertakan `worker` dan `pid`, sehingga mesin yang menolak autentikasi dapat diidentifikasi. Status antrean tidak menjamin pesan sudah diterima atau dibaca peserta.

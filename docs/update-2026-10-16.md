# Perbaikan komoditas dan pengingat notulensi

Komoditas yang dihapus tetap disimpan sebagai data nonaktif karena rekap sebelumnya masih merujuk kepadanya. Menambahkan nama yang sama, termasuk dengan perbedaan huruf besar atau spasi di tepi, kini mengaktifkan kembali komoditas tersebut. ID, nama, satuan, dan detail rekap lama dipertahankan. Nama yang masih aktif tetap ditolak sebagai duplikat.

Pengingat notulensi otomatis dikirim sekali pada H+1 pukul 09.00 WIB kepada setiap pegawai aktif yang ditugaskan sebagai notulis. Peserta biasa tidak menerima pesan ini. Sistem memakai tanggal Asia/Jakarta, termasuk ketika server memakai UTC.

- Jika backend baru menyala setelah pukul 09.00 pada H+1, antrean tetap diproses hingga akhir hari tersebut.
- Rapat yang dibatalkan atau sudah memiliki notulensi dilewati. Penugasan, revisi rapat, dan kelengkapan notulensi diperiksa lagi sebelum pengiriman.
- Nomor kosong ditampilkan sebagai “Nomor belum diisi”. Nomor yang dilengkapi sebelum akhir H+1 dapat diproses pada hari itu.
- Rapat yang lebih lama dari H+1 tidak otomatis menerima pesan susulan. Pengingat ini tidak diulang setiap hari.
- Antrean memakai kunci unik dan klaim pengiriman yang sudah ada. Hasil pengiriman yang tidak pasti tidak dikirim ulang otomatis.

Tidak diperlukan migration, perubahan schema `presensi`, atau workflow n8n baru. Pesan memakai jenis `reminder` pada webhook IPH yang sudah tersedia; riwayat aplikasi menampilkannya sebagai “Pengingat pengisian notulensi”.

Pengiriman memerlukan `WHATSAPP_AUTOMATION_ENABLED=true`, URL webhook yang benar, dan token backend yang cocok dengan workflow n8n. Pastikan semua backend yang memakai antrean yang sama memiliki konfigurasi yang sesuai. File `.env` server dipertahankan ketika memperbarui kode.

## Validasi lokal

Database pengujian terpisah dari database kantor. Permintaan pengiriman WA diganti dengan mock; pengujian tidak mengirim pesan sungguhan. Build backend, build frontend, dan lint dijalankan sebelum penyerahan.

- Backend PASS: 162 pengujian pada 13 berkas, termasuk pemulihan komoditas tanpa kehilangan detail rekap, jadwal WIB, penerima notulis, pembatalan, kelengkapan notulensi, nomor kosong, dan pencegahan pengiriman ganda.
- Hard Gate PASS untuk perubahan tampilan: 25 pemeriksaan browser tanpa runtime error; label notulensi diperiksa, filter dan tombol pengiriman ulang tetap bekerja melalui API mock. Sepuluh pemindaian aksesibilitas pada lebar 320, 390, 768, 1024, dan 1440 di kedua tema tidak menemukan pelanggaran otomatis WCAG A/AA; dialog rapat juga diperiksa.
- Purpose-Gate PASS: perubahan UI hanya memperjelas jenis pesan dan jadwal pengingat di panel riwayat yang sudah ada. Tidak ada aset, dekorasi, atau navigasi baru.
- Liveliness PASS dalam lingkup perubahan: desain CRM yang disetujui dipertahankan; Public Sans, aksen hijau, tema gelap biru, dan urutan panel vertikal tidak berubah. ENERGY 1 / RHYTHM 2 / MOTION 1 mengikuti fungsi panel sebagai riwayat operasional.
- Craftsmanship PASS dalam lingkup perubahan: label memakai bahasa Indonesia, status batas waktu berlaku untuk pengingat setelah rapat, dan pesan H+1 menjelaskan siapa penerimanya. Pemeriksaan browser mencakup riwayat, filter, pengiriman ulang, serta tampilan kedua tema dan lima lebar layar. Pemindaian otomatis tidak menggantikan pemeriksaan aksesibilitas manusia menyeluruh.

## Memasang ke server

Paket perubahan: `deploy/package.local/iph-batu-update-2026-10-16.tar.gz`. Paket hanya berisi file kode yang berubah, pengujian, dan dokumen ini; tidak memuat `.env` atau database.

Di PowerShell laptop, dari folder project:

```powershell
scp deploy/package.local/iph-batu-update-2026-10-16.tar.gz bps@192.168.100.10:~/
```

Di terminal SSH, buat cadangan kode dan build dahulu. Jalankan setiap perintah berurutan; hentikan jika ada yang gagal.

```bash
cd /opt/iph-batu
tar -czf ~/iph-batu-source-before-2026-10-16.tar.gz server/src/lib/whatsapp.ts server/src/routes/master.routes.ts server/src/routes/rapat.routes.ts src/components/RapatWhatsappStatus.tsx
tar -xzf ~/iph-batu-update-2026-10-16.tar.gz
npm run build -- --outDir dist-next
npm --prefix server run build -- --outDir dist-next
cp -a dist/assets/. dist-next/assets/
mv dist "dist-before-$(date +%Y%m%d-%H%M%S)"
mv dist-next dist
mv server/dist "server/dist-before-$(date +%Y%m%d-%H%M%S)"
mv server/dist-next server/dist
sudo systemctl restart iph-batu
curl -fsS https://iph.bpskotabatu.com/api/health
cd server
sudo -u iph-batu npm run wa:check
```

`wa:check` menguji koneksi dan token tanpa mengirim pesan. Jika hasilnya HTTP 401, samakan hanya token WhatsApp di `.env` server dengan token workflow, lalu restart layanan. Pembaruan kode tidak memperbaiki token yang salah.

Untuk memeriksa fitur, hapus lalu tambahkan kembali komoditas uji dan pastikan riwayat rekapnya tetap ada. Untuk pengingat notulensi, gunakan rapat uji dengan notulis dan nomor milik penguji; pada H+1 setelah pukul 09.00 WIB periksa riwayat Monitoring rapat. Rapat yang notulensinya sudah diisi harus dilewati.

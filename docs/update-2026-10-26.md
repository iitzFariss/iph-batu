# Memasang revisi 26 Oktober 2026

Paket sumber terbaru, termasuk perbaikan akses notulensi: deploy/package.local/iph-batu-update-2026-10-26-notulensi.tar.gz. Paket tidak menyertakan .env, node_modules, database, backup akun, token, atau berkas inspeksi lokal.

Migration dan perubahan akun sudah diterapkan pada database kantor dari workspace. Perintah migration berikut tetap aman dijalankan untuk memastikan server mengarah ke database yang benar; tidak memindahkan data ulang. Jangan menjalankan seed, reset atau transfer data untuk pembaruan ini.

Di PowerShell laptop dari root project:

```powershell
scp deploy/package.local/iph-batu-update-2026-10-26-notulensi.tar.gz bps@192.168.100.10:~/
ssh bps@192.168.100.10
```

Di terminal SSH server, siapkan sumber dan build baru. Jalankan tiap langkah hanya setelah langkah sebelumnya berhasil:

```bash
cd /opt/iph-batu
tar -czf "$HOME/iph-batu-before-20261026-$(date +%Y%m%d-%H%M%S).tar.gz" src server/src server/scripts server/prisma/schema.prisma server/prisma/migrations server/package.json server/package-lock.json
tar -xzf ~/iph-batu-update-2026-10-26-notulensi.tar.gz
npm --prefix server ci --include=dev
npm --prefix server run db:generate
npm --prefix server run db:status
npm --prefix server run db:migrate
npm --prefix server run db:check
npm run build -- --outDir dist-next
npm --prefix server run build -- --outDir dist-next
```

Setelah kedua build berhasil, aktifkan build baru:

```bash
cp -a dist/assets/. dist-next/assets/
mv dist "dist-before-20261026-$(date +%Y%m%d-%H%M%S)"
mv dist-next dist
mv server/dist "server/dist-before-20261026-$(date +%Y%m%d-%H%M%S)"
mv server/dist-next server/dist
sudo systemctl restart iph-batu
sudo systemctl is-active iph-batu
curl -fsS https://iph.bpskotabatu.com/api/health
```

Pertahankan konfigurasi .env produksi: PUBLIC_APP_URL dan CLIENT_ORIGIN memakai https://iph.bpskotabatu.com, koneksi PostgreSQL server tetap memakai port PostgreSQL server, bukan tunnel laptop. Jangan menyamakan JWT produksi dengan JWT development. Tautan notulensi memakai kunci bersama di database, terpisah dari JWT login.

Sesudah aktif, Ctrl+Shift+R dan masuk kembali sebagai admin@bpskotabatu.com. Periksa:

1. Dashboard: N/A untuk data kosong, filter frekuensi bulan/tahun.
2. Input: angka empat desimal; unduh template, isi sheet Data IPH, unggah, cek pratinjau dan impor menggunakan periode uji yang belum tersimpan.
3. Rekap: tanpa rentang tanggal/intervensi; CSV dan Excel tanpa cutoff/status, andil empat desimal.
4. Visualisasi: pilih satu tahun, periksa statistik mengikuti pilihan dan rincian tambahan sudah hilang.
5. Kelola rapat: cari notulis, pisahkan lokasi/link rapat, buat tautan notulensi. Gunakan nomor milik penguji bila menguji undangan nyata.
6. Buka tautan undangan di ponsel: judul/notulis benar, countdown muncul, simpan hasil dan periksa Hasil rapat. Pengisian sebelum jadwal tidak menutup rapat mendatang.
7. Analisis teks: edit template dengan penanda data, simpan, muat ulang dan pilih periode lain. Isi data harus mengikuti periode, sementara susunan kalimat mengikuti template tersimpan.
